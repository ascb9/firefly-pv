## 重新合成

需要ffmpeg、ffprobe、Python3，以及两个输入：原版 `雪为何色.mp4` 和修订前的 `雪为何色_流萤角色替换_V1.6_镜头修订.mp4`。为避免重复占用空间，完整输入视频不包含在工程压缩包中。

```bash
python3 -m pip install -r requirements.txt
python3 shot54.py \
  --original '/path/to/雪为何色.mp4' \
  --base '/path/to/雪为何色_流萤角色替换_V1.6_镜头修订.mp4' \
  --output '/path/to/雪为何色_流萤角色替换_V1.7_分镜与运镜精修.mp4' \
  --qa-dir qa/final_v17
```

仅复核54秒镜头，添加 `--preview --preview-window smile`；仅复核腿脚及接吻镜头，添加 `--preview --preview-window early`。这些操作复用现有图片，无需重新绘制。

```bash
python3 verify_v17.py \
  --candidate '/path/to/雪为何色_流萤角色替换_V1.7_分镜与运镜精修.mp4' \
  --original '/path/to/雪为何色.mp4' \
  --base '/path/to/雪为何色_流萤角色替换_V1.6_镜头修订.mp4' \
  --output-dir qa/final_v17 --full \
  --comparison 'qa/原PV并排对照.mp4'
```

核验区分合成前完全静止与H.264编码后的细小像素差异，并检查音频包是否与原版一致。视觉对照使用实际MP4解码画面；角色替换后的像素差异不适合用全画面相似度判断美术质量。

`compose.py`、`revisions.py`等旧版入口继续保留，用于复用之前镜头。直接复现本次交付请使用 `shot54.py`。
