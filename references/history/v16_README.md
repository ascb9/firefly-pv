# 雪为何色 · 流萤角色替换 V1.6 镜头修订

本工程在已交付的 V1.5 成片上进行指定镜头修订。继续沿用 59 张既有完整画面关键帧及原来的角色动画、歌词状态、接吻演出和原版奔跑段。本次图像生成仅调用一次，用于补齐微笑镜头被裁切的角色边缘，得到可入退场的透明角色层。变身器使用原有网格、正背面纹理及旋转角度，修改的是原生渲染材质与合成光影。

时间采用原视频的实际切点，30 fps，帧号从 0 开始，区间左闭右开。用户给出的秒数用于定位镜头，没有为追求整数秒而移动歌词或音轨。

## 文件与复现

- `revisions.py`：当前修订版的主合成程序。
- `compose.py`：保留的完整 V1.5 合成流程。
- `captions.py`、`captions.json`：依据原片同一帧号读取歌词显示及高亮。
- `cocoon_3d.py`：原生网格旋转渲染，含新的冰蓝材质、透明翼面及正确的透明边缘处理。
- `assets/a13_exit_cel.png`：本次唯一新增生成的透明角色层。
- `new_cutout_prompt.txt`：本次图像生成的完整提示词与输入信息。
- `manifest.json`：来源、父版本、镜头区间与最终核验记录。
- `qa/`：关键帧、最终编码预览、固定区域核验、角色轨迹、歌词状态与媒体检查。

需要 Python 3、FFmpeg，并安装 `requirements.txt`。仅重新渲染变身器时需要 ModernGL/EGL；既有 70 张旋转帧已经包含在包内。原版、V1.4 和 V1.5 视频已在此前交付，工程包不重复内嵌这些大型输入文件。将三个视频路径替换为实际路径即可复现：

```bash
python3 revisions.py \
  --source /path/to/V1.4.mp4 \
  --original /path/to/original.mp4 \
  --base /path/to/V1.5.mp4 \
  --output /path/to/V1.6.mp4

python3 verify_revision.py \
  --video /path/to/V1.6.mp4 \
  --original /path/to/original.mp4 \
  --v14 /path/to/V1.4.mp4 \
  --v15 /path/to/V1.5.mp4
```

输出保持 1920×1080、30 fps、2764 帧。原版 AAC 音轨直接复制，帧时钟、歌词和音轨都没有独立偏移。颜色编码明确使用 BT.709 转换。本工程以二维角色层、既有插值、刚性镜头和原生物件渲染完成修订；没有重新制作奔跑动画。

变身器设计参考沿用已核对的官方来源：<https://toy.bandai.co.jp/ja/item/01_21239/>。
